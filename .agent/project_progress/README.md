# 项目进度管理体系

本目录是项目进度的**唯一事实来源**，分为三层：

```
.agent/project_progress/
  BOARD.md              # 任务看板：随时一眼看清宏观哪个阶段、微观哪个迭代（必须保持同步）
  README.md             # 本文件：体系规则
  macro/ROADMAP.md      # 宏观：项目总进度 — 里程碑、功能模块开发/合并/测试/发版关键信息
  iterations/IT-XXX-*.md  # 微观：每个迭代一个文件 — 目标、任务清单、完成情况
```

## 规则（agent 必须遵守）

1. **开始任何工作前**：先读 `BOARD.md`，确认当前所处宏观阶段和微观迭代。
2. **完成任何工作后**：
   - 更新对应迭代文件的任务状态（勾选 / 补充记录）
   - 若进度有变化，**同步更新 `BOARD.md`**（"当前位置" + 进度快照 + 更新日期）
   - 跨阶段的关键决策、发版信息记录到 `macro/ROADMAP.md`
3. **宏观**回答"项目整体进行到哪一步了"：功能开发 → 合并 → 测试 → 分发发版。
4. **微观**回答"这一小段（迭代）要做什么"：
   - 每个迭代有明确目标、可勾选的任务清单、完成日期
   - 一个迭代只解决一个主题，完成即归档（任务全勾选 + 写"完成记录"）
   - 开新迭代时新建 `IT-XXX-主题.md`，编号递增，旧文件只读不改
5. 状态符号：✅ 完成 · 🔵 进行中 · ⬜ 未开始 · ⛔ 阻塞
