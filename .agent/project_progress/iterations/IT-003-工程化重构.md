# IT-003 工程化重构：目录结构 / examples / 规范

- 状态：✅ 完成（2026-08-22）
- 所属里程碑：M3 功能扩张（前置工程化地基）

## 目标

把工程从"能跑的扁平结构"升级为"可扩展的库结构"，并沉淀规范、补齐教学示例，
为 M3 批量加端点铺路。

## 任务

### 目录重构（src/opencode_client/）
- [x] `errors.py`：`OpenCodeError`/`OpenCodeApiError` 从 client.py 拆出
- [x] `constants.py`：默认超时、User-Agent 等常量
- [x] `models/` 拆包：`base`（OpencodeModel + `id_alias`）、`session`、`message`、
      `part`、`discover`（agent/provider/command/health）、`event`，子包 `__init__` re-export
- [x] `resources/` 资源层（组合式，非继承）：`base`（Resource + `query_params`）、
      `sessions`（SessionsResource：CRUD/fork/abort/share/summarize/messages/prompt/permission）、
      `server`（ServerResource：health/config/provider/agent/command/event stream）；
      API 由扁平改为 `client.sessions.create()` / `client.server.health()` 分组风格（对齐官方 SDK）
- [x] `client.py` 瘦身：构造 + 生命周期 + `send`/`build_request` 传输 + `sessions`/`server` 入口挂载
- [x] `sse.py`：`SSEDecoder` + `EventStream` 一起收编，全量 docstring
- [x] 全模块 `__all__` + 全类/全公开函数 docstring（ruff `D` 规则强制）
