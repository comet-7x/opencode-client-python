# IT-002 核心功能：会话/消息/事件流

- 状态：✅ 完成（2026-08-22）
- 所属里程碑：M2 核心功能
- API 依据：`learning_log/get_opencode_api/opencode_rest_api.json`（opencode v1.18.1 导出）

## 目标

打通"连接 opencode serve → 建会话 → 发消息 → 流式收事件"核心链路，并用真实服务验证。

## 任务

### 模型层（models.py）
- [x] `OpencodeModel` 基类 + `_id_alias` 生成器（camelCase + 大写 ID，如 `session_id`→`sessionID`）
- [x] `Session` 全套（snapshot/tokens/time/share 嵌套）
- [x] `UserMessage` / `AssistantMessage`（discriminated union on `role`）
- [x] `Part` 11 种（text/file/tool/reasoning/snapshot/step-start/step-finish/patch/agent/retry/compaction，union on `type`）
- [x] `ToolState` 4 状态 union、`FilePartSource` 3 源 union
- [x] 请求模型：`CreateSessionRequest` / `UpdateSessionRequest` / `PromptModel` / `PromptPart`（Text/File/Agent/Subtask 输入）
- [x] 外围：`Health` / `Agent` / `Provider` / `ProviderList` / `Command`
- [x] `Event` 泛型（`type` + `properties: dict`；v1 事件 94 种不逐一建模）

### SSE（sse.py）
- [x] `SSEDecoder`：data 多行拼接、comment 忽略、非 JSON 兜底、EOF flush；sync（`iter_events`）+ async（`aiter_events`）
- [x] 单测 8 项（多事件同 chunk、comment、EOF 半事件、非 JSON、多 data 行、async 流）

### 客户端（client.py）
- [x] `OpenCodeClient`：httpx.AsyncClient 封装、BasicAuth、上下文管理
- [x] session：list / create / get / update / delete / fork / abort / share / unshare / summarize
- [x] 消息：prompt（str 或 parts 列表，model 接受 `PromptModel | dict`）/ prompt_async / list_messages / delete_message
- [x] `stream_events()` → `EventStream` 异步上下文管理器（`client.send(stream=True)`，全程无 Any）
- [x] 发现类：health / get_config / update_config / list_providers / list_agents / list_commands
- [x] `respond_permission`
- [x] 统一 `OpenCodeApiError(status_code, payload)`；响应解析走模块级 `TypeAdapter` 常量

### 测试与验证
- [x] respx 单测（tests/test_client.py 12 项 + test_sse.py 8 项）：alias 序列化断言、union 反序列化、错误路径
- [x] 真实服务验证（opencode v1.18.1 @ 127.0.0.1:20001，无密码）：
  建会话 → prompt（steins-middleware/Qwen3.8-27B 回答 "pong"）→ SSE 92 deltas + session.idle
  → 历史 union 解析 → abort / fork / delete 全通过
- [x] 质量门禁全绿：ruff / format / mypy(src+tests) / pyright strict / pytest（20 项）
